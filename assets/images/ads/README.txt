Mechanics tab ad banner images.

Drop 16:9 images here named ad_1.jpg, ad_2.jpg, ad_3.jpg (or update the
paths in lib/core/data/mechanics_ads_data.dart to match whatever you name
them). The carousel on the Mechanics tab cycles through whatever is
listed in that file — add, remove, or reorder entries there any time you
change the ad set. Each entry can also carry a `url` that opens when the
banner is tapped; leave it null for a purely visual placeholder slot.
